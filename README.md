Temperature Converter

The purpose of this task is to use JUnit 4 to create simple unit tests.

Evaluation criteria:

Description

Create a Java program for converting temperature scales and develop appropriate unit tests. Use JUnit 4 for the unit tests.

Provide and test the following conversions:

Fahrenheit to Celsius
Fahrenheit to Kelvin
Celsius to Fahrenheit
Celsius to Kelvin
Kelvin to Fahrenheit
Kelvin to Celsius

Assumption: Eclipse and JDK 17 are installed.
